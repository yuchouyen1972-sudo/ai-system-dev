# Feature Specification: BEAR FVG 空頭失衡延續——可執行策略回測器

**Feature Branch**: `005-bear-fvg-strategy-backtest`

**Created**: 2026-11-22

**Status**: Draft

**Input**: User description: "依 spec 004 全史驗證結論（BEAR FVG 唯一可交易構想：dedup 淨 +19~+23 點、三年超額穩定；但書＝無停損/滑價/持倉管理），將其從事件研究期望值量測升級為可執行策略回測——單口滾動、停損設計、滑價情境、權益曲線與誠實策略判定"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 可執行策略回測器 (Priority: P1)

量化研究者在完整歷史 1m 資料上執行「BEAR FVG 做空」策略回測：單口滾動互斥執行（同一時間至多一筆持倉）、進場＝訊號次根開盤價（含不利滑價）、停損＝缺口上緣＋波動 buffer（構想語義：缺口被回補＝失衡失效）、停利＝固定風報比、遠景上限出場、跨盤強平（日盤 13:40／夜盤 04:55 收盤價平倉，不在休市段持倉）。回傳逐筆交易（含出場原因）與權益曲線統計。

**Why this priority**: 本功能核心——把 004 的「構想有正期望」升級為「策略可執行且數字誠實」。

**Independent Test**: 對合成資料（已知缺口/停損情境）單獨呼叫回測器，逐筆結果可手算複核。

**Acceptance Scenarios**:

1. **Given** 合成的 BEAR 缺口後續下跌段，**When** 執行回測，**Then** 產生一筆空單，進場價＝次根開盤−滑價，出場原因與價格符合規則。
2. **Given** 持倉期間價格反彈觸及停損（缺口上緣＋buffer），**When** 當根 high ≥ 停損價，**Then** 以停損價＋不利滑價回補，出場原因＝SL。
3. **Given** 持倉跨越 13:40（日盤）或 04:55（夜盤），**When** 到達強平時點，**Then** 以該根收盤價平倉（EOD_FLAT），不跨休市段持倉。
4. **Given** 前一筆尚未出場，**When** 新訊號出現，**Then** 該訊號被跳過（互斥），不得同根或重疊持倉。

---

### User Story 2 - 滑價×成本情境矩陣 (Priority: P2)

量化研究者取得滑價 0/1/2 點（進出各計、往不利方向）× 實證成本區間雙值的完整淨期望矩陣，並以**最嚴情境（滑價 2＋成本上限）**作為策略判定依據，三分法輸出（可執行／不可執行／待調參）。

**Why this priority**: 004 的教訓——「可交易構想」≠「可執行策略」，滑價與成本是主要殺手，必須矩陣化揭露。

**Independent Test**: 矩陣 3×2 全列，任一格可由逐筆交易重算複核。

**Acceptance Scenarios**:

1. **Given** 全史回測完成，**When** 報告生成，**Then** 3 滑價 × 2 成本＝6 格淨期望完整呈列，無遺漏。
2. **Given** 最嚴情境淨期望 ≤ 0，**When** 報告生成，**Then** verdict＝不可執行，且不得以較樂觀情境取代判定。

---

### User Story 3 - 分年穩定性與事件研究對照 (Priority: P3)

量化研究者取得分年切片（筆數/勝率/期望值）與 004 事件研究基準（dedup H=15，raw +27.0）的並列對照，並揭露差異歸因（停損截斷右尾 vs 固定遠景全取；強平提前出場）。

**Why this priority**: 防止「回測器寫壞了但總數看起來還行」——分年與對照是誠實性的結構保障。

**Independent Test**: 分年數字之和＝全體；對照表差異可歸因至出場規則差異。

**Acceptance Scenarios**:

1. **Given** 全史回測，**When** 報告生成，**Then** 分年（2024/2025/2026）切片呈列且合計一致。
2. **Given** 事件研究基準 +27.0 點，**When** 策略期望值顯著低於基準，**Then** 報告須列出差異歸因（停損/強平/滑價各自影響）。

---

### Edge Cases

- 停損與停利同根雙觸：**保守取停損**（先 SL 後 TP 慣例，與 004 外部腳本檢討一致）。
- 缺口上緣 ≤ 進場價的異常結構（資料異常）：跳過該訊號並於報告計數。
- 強平時點棒不存在（資料缺口）：以強平時點前最後一根收盤價平倉。
- 滑價後進場價異常（≤0）：防禦性跳過並計數。
- 進場根即為強平根：允許進場後立即強平（時間邊界誠實處理）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: System MUST 單口滾動互斥執行：下一筆進場根須嚴格晚於上一筆出場根。
- **FR-002**: System MUST 以訊號次根開盤價減不利滑價進場（做空）；禁止同根出進與前視。
- **FR-003**: System MUST 預設停損＝缺口上緣＋SL_BUFFER_ATR×ATR，並支援參數化（最小停損點數下限、ATR 倍數法對照組）。
- **FR-004**: System MUST 含停利（風報比參數化）、遠景上限出場、跨盤強平（日盤 13:40／夜盤 04:55 收盤價平倉）。
- **FR-005**: System MUST 支援滑價 0/1/2 點三情境，進出各計、往不利方向。
- **FR-006**: System MUST 沿用實證成本區間雙值（手續費 30~50 元來回＋期交稅）。
- **FR-007**: System MUST 產出逐筆交易 CSV＋權益曲線統計（筆數/勝率/PF/期望值/MDD/平均持有根數）＋事件研究對照＋分年切片，輸出僅終端與檔案。
- **FR-008**: System MUST 以最嚴情境（滑價 2＋成本上限）作為 verdict 依據，三分法輸出。
- **FR-009**: System MUST 不改動既有 004 偵測器與資料鏈行為（純新增）；所有常數命名並註來源。
- **FR-010**: System MUST 於完整歷史 5 分鐘內完成回測。

### Key Entities *(include if feature involves data)*

- **StrategyTrade**: 進/出時間、方向、進/出價、出場原因（SL/TP/HORIZON/EOD_FLAT）、原始點數、成本、淨點數、持有根數。
- **EquitySummary**: 筆數、勝率、PF、期望值、MDD、平均持有、verdict、情境參數快照。
- **SlippageMatrix**: 滑價×成本雙值矩陣（3×2）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 全史回測耗時 < 5 分鐘。
- **SC-002**: 產出 trades CSV＋summary MD（含情境矩陣與對照）。
- **SC-003**: 合成案例結構斷言 PASS（停損/強平/互斥/次根進場）。
- **SC-004**: 滑價矩陣 3×2 完整。
- **SC-005**: 分年切片三年呈列且合計一致。
- **SC-006**: 既有測試台（27 項）維持 ALL PASS（回歸保護）。

## Assumptions

- 沿用 004 偵測器（U10 BEAR FVG）、成本模組、1m parquet 資料鏈。
- 單口微台（POINT_VALUE_TWD=10）；無部分成交/流動性/容量模型（揭露限制）。
- H_MAX=60 根遠景上限（沿 004 research D5）；停利風報比預設 1.5（對照外部腳本 1:1.5）。
- 強平時點沿外部腳本慣例（13:40/04:55，棒存在已實測）。
